Plunder Ledger app icon (every file in this directory: plunder-ledger-1024.png,
plunder-ledger-macos-512.png, plunder-ledger.icns, plunder-ledger.ico, hicolor/).

Original artwork drawn in code for Plunder Ledger (crates/ui-egui/src/brand/icon.rs) and rendered
by `cargo run -p gridcraft-ui-egui --example app_icon -- assets/app-icon`. No third-party material.
